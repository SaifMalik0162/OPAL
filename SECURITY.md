# Security policy

## Supported versions

Only the latest OPAL alpha build is supported for security fixes. Older alpha
builds may no longer receive updates. Check the current release notes for the
latest version and its known limitations.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** feature for this repository so
the report stays private. Do not open a public issue or discussion containing
exploit details, credentials, personal data, audio, notes, or a library backup.

If private vulnerability reporting is unavailable, contact the repository
owner through their GitHub profile to request a private reporting route. Do not
post technical details publicly while waiting.

Reports should include the affected OPAL version, operating system and
architecture, impact, and concise reproduction steps. Remove personal paths and
user content from logs and screenshots before sharing.
