# Contributing to OPAL

OPAL is proprietary software and is not currently accepting code contributions
or pull requests. Do not submit code or assets unless the maintainer has first
invited that contribution in writing. See [`LICENSE`](LICENSE) for the terms
that apply to public source access.

Bug reports and feature requests are welcome through GitHub Issues. Use the
provided issue form and include the OPAL version, operating system, and device
architecture. Do not attach audio, private notes, library backups, credentials,
full personal file paths, or unreviewed diagnostics. Report security issues
privately as described in [`SECURITY.md`](SECURITY.md), not through a public
issue.

For invited alpha testing, follow the feedback instructions included with your
build.
